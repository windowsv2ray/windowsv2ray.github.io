一、Quantumult X 是什么？它的定位远超代理工具

Quantumult X（以下简称QX）不仅仅是一个普通的代理客户端，它是一套网络管理解决方案。其核心定位是——为用户提供完整、透明、可控的网络请求处理逻辑。

在安卓版本中，QX保留了大部分iOS核心功能，并加入了一些平台特性，让安卓用户也能享受到高级代理技术带来的便利与自由。

核心能力概览：

  • 支持多协议代理：包括 HTTP、HTTPS、SOCKS5、Shadowsocks、Vmess 等。

  • 灵活的规则配置系统：支持根据域名、IP、关键词等设定行为逻辑。

  • 自定义 DNS 服务：提高解析速度，绕过DNS污染。

  • 分流与重定向支持：可将不同应用或网站的流量分配给不同的节点或策略。

  • 实时流量监控和日志记录：网络行为透明可见，方便排错与优化。

  • 自动更新订阅与规则集：支持外部订阅链接，轻松实现节点批量管理。

在功能层级上，QX几乎达到了商用级别的网络管理水平，却以极简的方式呈现给终端用户，可谓“简洁中见锋芒”。

三、Quantumult X 配置实战：从零开始掌握核心能力

真正让Quantumult X发挥价值的，是它强大的配置系统。以下将从基础代理设定开始，一步步讲解如何打造属于你的QX网络规则体系。

1. 添加代理服务器节点（节点来源）

要实现科学上网，首先需要代理节点。节点来源一般有三种：

  • 购买付费节点订阅（推荐）：如Clash、V2ray、Trojan等服务商提供的订阅链接，稳定、安全。

  • 使用免费分享节点：不稳定，安全性低，适用于测试和临时访问。

  • 自建节点：成本高但可控，适合高阶用户。

导入方式：

  • 打开Quantumult X主界面，点击右上角“+”，选择“通过订阅链接导入”；

  • 粘贴你的订阅链接；

  • 导入后会自动更新节点列表。

2. 设置DNS服务器

DNS 是网络访问中的第一步，决定了你能否顺利访问目标网站。

推荐配置：

  • Cloudflare DNS：1.1.1.1 / 1.0.0.1

  • Google DNS：8.8.8.8 / 8.8.4.4

在设置中手动输入DNS地址，建议开启 DNS-over-HTTPS 或 DNS-over-TLS，防止DNS污染。

3. 自定义规则分流

这是Quantumult X最有价值的部分。你可以将如下流量自动分流：

  • 国内网站 → 直连

  • 国际网站（如Twitter、YouTube）→ 走代理

  • 广告域名 → 拦截

  • 游戏类请求 → 分配特定节点（如低延迟日本节点）

示例规则：

ini
[filter]
IP-CIDR,192.168.0.0/16,DIRECT
DOMAIN-SUFFIX,twitter.com,Proxy
DOMAIN-KEYWORD,google,Proxy
GEOIP,CN,DIRECT
FINAL,Proxy

规则执行顺序从上到下，最后一条是“兜底规则”，未命中其他规则的流量将默认走 Proxy。

4. 快速启用和切换代理

在主界面中可快捷开启/关闭代理服务，还可在不同代理策略之间切换。

建议模式：

  • 工作时：规则分流

  • 下载大文件或看视频时：全局代理

  • 网络调试时：直连或记录日志模式

Q1：Quantumult X和Clash有何区别？

  • Clash 更适合进阶用户和大规模配置管理；

  • QX 更注重规则控制、数据分析，界面更简洁。

  • 两者都支持订阅，但QX的规则引擎更细腻。

Q2：安卓Quantumult X是否安全？

  • 官方版本为签名版，未发现恶意行为；

  • 避免使用第三方篡改版；

  • 若担心隐私，可配合Orbot等工具使用。

Q3：如何解决连不上节点的问题？

  • 检查订阅是否过期；

  • 切换不同节点；

  • 手动Ping测试目标IP；

  • 尝试换DNS为1.1.1.1/8.8.8.8。

Q4：Quantumult X需要付费吗？

  • 基础功能免费；

  • 高级功能如任务调度、强规则管理可能需订阅；

  • 订阅一次性购买授权，非强制，但值得投资。

FAQ

Nekoray 支持节点订阅批量更新吗？
支持。用户可通过订阅 URL 批量更新节点，程序会自动下载并替换旧节点。定期更新保证节点列表始终可用，减少手动维护，提高使用效率和便利性。
VLESS + XTLS 如何降低移动网络延迟？
XTLS 通过减少握手次数和加密开销降低延迟。结合策略组和多节点切换，可在高延迟或不稳定的移动网络环境中保持连接稳定，提升网页浏览、视频和游戏体验流畅度。
Sing-box 如何实现精确域名分流？
Sing-box 可以按域名设置分流规则，将不同流量发送到指定节点。结合策略组使用，可实现网页、视频和游戏流量精准分配，提高访问速度和网络稳定性。
Trojan 节点无法连接时应如何排查？
遇到 Trojan 无法连接时，需检查服务器证书是否有效、端口是否开放、密码配置是否匹配。还应确认防火墙未阻断相关端口，并尝试切换 TLS 版本或使用 IP 地址连接。
Trojan 的证书配置错误会导致什么问题？
如果 TLS 证书无效或域名不匹配，Trojan 客户端将无法建立安全连接，导致节点无法使用。需要确保证书有效、域名正确，才能保证正常访问。
Surfboard 的配置文件可以手动编辑吗？
Surfboard 的配置文件是基于 YAML 格式的文本文件，可以手动编辑。通过修改策略、节点组或规则部分，用户可自由定制代理逻辑，也可通过导入订阅实现自动更新。
V2Ray 的核心组件有哪些？
V2Ray 的核心由 inbound、outbound、routing、policy 等模块组成。Inbound 处理入站请求，Outbound 负责出站连接，Routing 管理流量分流策略。模块化的设计让用户可以自由组合代理方式。
Mihomo 节点分组如何保证低延迟访问？
将节点按延迟、地区或用途分组，并启用策略组，系统会根据节点健康和延迟自动选择最佳节点。保证网页浏览、视频播放和游戏流量的低延迟稳定连接。
如何在 Nginx 上为 Vmess/WS 配置反向代理与 TLS？
在 Nginx 中配置 HTTPS 站点并将特定路径（如 /ray）反向代理到 V2Ray 的 WebSocket 端口，确保 proxy_set_header 设置正确（Host、X-Real-IP 等）。同时使用 certbot 获取并自动续期 TLS 证书以维护安全。
Nekoray 的订阅更新支持自动导入节点吗？
支持。Nekoray 可以通过订阅 URL 自动下载节点，并根据用户配置更新本地节点列表。定期更新确保节点始终可用，减少手动维护的麻烦，提高使用便利性。
